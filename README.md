# Keepsake
Keepsake is a reliable, open-source, and easy-to-use password manager.

## Features:

Custom password generation
Ability to save generated passwords
MASTER Password (security password requested at startup)
Encrypted password storage
Configurable encryption
Light and Dark themes


## Running the application:

1: Download the stable version from the Releases page.
2: Extract the downloaded "keepsake.zip" file.
3: Navigate to the folder where you extracted "keepsake.zip".
4: Run "Keepsake.exe" located in the main directory.
